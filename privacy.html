Privacy Policy

Last updated November 11, 2026

What the app does

Jackass Uploader is a desktop application that uploads videos I choose to my own social media accounts (YouTube, TikTok, Instagram, Facebook) using each platform's official API, at times I schedule.

Data it accesses

When I connect an account, the platform gives the app an access token limited to the permissions I approve (for example uploading videos and reading my channel or profile name and picture). The app uses this only to upload and manage the videos I schedule, and to show which account is connected.

Where data is stored

Tokens, settings and scheduled videos are stored only on my own computer, encrypted with Windows data protection. Nothing is sent to any server other than the platforms themselves (Google/YouTube, TikTok, Meta). No data is sold, shared with third parties, or used for advertising or analytics.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. You can revoke the app's access at any time at Google security settings.

Deleting data

Disconnecting an account in the app, or deleting the app's data folder, removes all stored tokens. Access can also be revoked from each platform's account settings.
